图 1：零部件设计智能体机制架构示例
============================================================

图 1 的定位：
图 1 的主体是“零部件设计智能体机制骨架”，并在这个骨架内展示一个“Skill-工具-资料调用网络示例”。

这张图不是完整软件架构图，也不是知识图谱图。

图 1 要表达的核心主轴：

LLM 任务理解与调度
  -> Skill 路由 / 编排
  -> 运行中的设计上下文
  -> skill 调用工具
  -> 工具读取业务资料
  -> 中间结果回填上下文
  -> 执行生成

建议画面布局：

上层：
LLM 任务理解与调度
- 识别任务类型
- 判断缺失信息
- 规划 skill 调用顺序
- 解释结果与权衡

中层核心：
运行中的设计上下文
这是整张图的核心骨架节点，不是知识图谱，也不是数据库。
建议画成一个中心状态面板，内容包括：
- part = 连杆
- intent = 参数化设计 / 优化
- known_params = 已知参数
- missing_params = 缺失参数
- selected_template = 已选模板
- formulas = 变量依赖表
- constraints = 风险约束清单
- optimization_problem = 待构造
- solver_config = 求解器配置
- deliverables = 输出物清单

围绕中心上下文分布 skill：
- 需求解析 skill
- 资料检索 skill
- 模板推荐 skill
- 公式解析 skill
- 风险审查 skill
- 优化建模 skill
- 执行生成 skill

每个 skill 要体现：
- 输入是什么
- 调用什么工具
- 产出什么中间结果
- 中间结果如何回填到运行中的设计上下文

左侧或下方展示“工具-资料调用示例”：

公式解析 skill：
- 调用经验公式表解析工具
- 调用 NX 表达式读取工具
- 调用模板公式读取工具
- 读取 100+ 经验公式表
- 读取约 370 条 NX 表达式
- 产出变量依赖表、公式计算链、可优化变量候选

风险审查 skill：
- 调用 DFMEA 表解析工具
- 调用 P 图 / 边界图解析工具
- 调用规范校核工具
- 读取 200+ DFMEA 风险规则
- 读取 P 图、边界图、设计规范条款
- 产出风险防错项、约束清单、证据来源

右侧展示执行工具与业务输出：
- 优化求解工具：最优参数、备选方案、约束满足情况
- NX 自动化工具：更新表达式、重建参数化模型、自动标注
- 报告 / 出图工具：设计说明书、二维图纸、关键参数属性表
- DFMEA 更新工具：风险依据回写、防错项说明
- TC 回写工具：发布、升版、历史模板沉淀

图 1 需要突出显示的资料厚度：
- 100+ 经验公式表
- NX 表达式约 370 条
- DFMEA 风险规则 200+
- P 图 / 边界图
- 设计规范
- 设计说明书
- 历史模板

图 1 的一句话表达：
零部件设计智能体通过 LLM 调度、skill 编排和工具调用，把业务资料转化为运行中的设计上下文，再逐步形成可求解、可执行、可追溯的设计任务。


============================================================
图 2：零部件设计智能体运行示例
============================================================

图 2 的定位：
图 2 展示一次具体运行过程，重点是智能体如何使用图 1 中的 skill 和工具，获取业务知识，构造优化问题，并完成优化求解和工程输出。

图 2 的核心主轴：

用户 / 业务系统输入
  -> LLM 理解任务
  -> skill 获取业务知识
  -> LLM 引导问题收敛
  -> 优化问题构造
  -> 优化器求解
  -> LLM 解释结果
  -> NX / 出图 / 报告 / TC 回写

推荐布局：

左侧：知识获取与问题收敛
- 用户 / 业务系统输入
- 需求解析 skill
- 资料检索 skill
- 模板推荐 skill
- 公式解析 skill
- 风险审查 skill
- LLM 追问缺参、缩小变量范围

中间：优化问题构造与求解核心
这是图 2 最大的视觉中心。

优化问题应明确展示四类对象：

1. 设计变量 x
- 连杆中心距
- 大头直径
- 小头直径
- 杆身厚度
- 腹板厚度
- 圆角半径

2. 固定参数 p
- 机体高度
- 行程
- 缸径
- 曲柄半径
- 活塞压缩高度
- 连杆瓦厚度

3. 目标函数 F(x,p)
- 轻量化
- 安全裕度最大化
- 变形 / 间隙裕度最大化
- 加工成本或通用性

4. 约束条件 C(x,p)
- 安全系数 >= 1.2
- 衬套面压 < 140 MPa
- 运动轨迹间隙 >= 5 mm
- 螺栓覆盖系数 >= 2
- DFMEA 高风险项不得触发

优化器配置：
- 算法：遗传算法、贝叶斯优化、网格搜索或其他优化器
- 初值：来自模板
- 变量上下限：来自公式、规范和用户确认
- 目标权重：由用户和 LLM 辅助设定
- 约束优先级：DFMEA 高风险优先
- 终止条件：迭代次数、收敛阈值

优化求解过程：
- 生成候选参数
- 调用公式计算
- 调用校核脚本
- 检查规范约束
- 检查 DFMEA 风险
- 过滤不可行解
- 记录迭代过程
- 输出最优方案和备选方案

右侧：工程生成与业务回写
- NX 参数化模型
- 二维图纸 / 自动标注
- 设计说明书
- 关键参数属性表
- DFMEA 风险清单更新
- TC 发布 / 升版
- 历史模板沉淀

底部：人机评审反馈闭环
- 参数缺失 -> LLM 按公式依赖追问用户
- 方案不可行 -> skill 返回违反的约束或风险项
- 用户不满意 -> LLM 解释权衡，引导调整目标权重或变量范围
- 方案通过 -> 生成设计包并回写业务系统

图 2 的一句话表达：
智能体不是直接生成设计结果，而是通过 skill 和工具获取业务知识，把业务知识转化为变量、目标、约束和求解器配置，再由优化算法求解，最后调用 NX 和报告工具生成工程交付物。
