## 三、核心参数计算
### 3.1 连杆中心距（大小头孔中心距离）
```
连杆中心距 = 机体高度 - 压缩余隙 - 活塞压缩高度 - 缸盖垫厚度 - 连杆瓦厚度 - 曲柄半径 - 连杆小头衬套厚度
= 350 - 0.7 - 71.5 - 1.7 - 2.5 - 67.5 - 2
= 204.1 mm
```

### 3.2 连杆大头孔直径
```
连杆大头孔直径 = 连杆轴颈直径 + 2×连杆瓦厚度
= 83 + 2×2.5
= 88 mm
```

### 3.3 连杆小头孔直径
```
连杆小头孔直径 = 活塞销直径 + 2×小头衬套厚度
= 47 + 2×2
= 51 mm
```
