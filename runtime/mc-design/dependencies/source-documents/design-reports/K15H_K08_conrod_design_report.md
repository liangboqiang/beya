## 3. 设计参数修改记录
### 3.1 核心参数计算
- 连杆小头直径 = 活塞销直径 + 小头衬套厚度 = 47 + 2 = **51mm**
- 连杆大头直径 = 连杆轴颈直径 + 连杆瓦厚度 × 2 = 83 + 2.5×2 = **88mm**
- 连杆中心距 = 机体高度 - 压缩余隙 - 活塞压缩高度 - 缸盖垫厚度 - 曲柄半径 = 350 - 0.7 - 71.5 - 1.7 - 67.5 = **208.6mm**
