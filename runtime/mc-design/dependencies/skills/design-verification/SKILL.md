# 设计验证技能

## 适用场景

用于检查参数修改、TC 模板库主模型选择、报告内容或外部系统结果是否与用户需求和工具结果一致。

## 验证方法

1. 核对用户原始需求、已确认输入和工具返回结果。
2. 参数类任务核对标准参数候选、NX 当前参数、修改前后值和失败项。
3. 模板类任务核对候选是否来自 TC `智能体模板库`、用户确认、打开的 TC 对象/文件路径和当前 WorkPart。
4. 报告类任务核对槽位清单、已填槽位、缺失槽位和导出文件。
5. 外部系统类任务核对查询条件和返回状态，避免把空结果解释成成功结论。

## 输出要求

输出“已验证项、风险项、需要用户确认项”。无法验证时说明缺少哪类证据，不编造结果。
