# DFMEA 风险复核技能

## 适用场景

用于对设计变更、参数调整、材料/结构方案或报告内容进行失效模式和风险复核。当前稳定生成链路优先服务连杆 DFMEA；正式交付只复制真实 `.xls` 模板，不改内容。曲轴和凸轮轴可做风险复核摘要，但没有对应模板前不得声称已生成正式 DFMEA。

## 参考模板

用户提供的参考 `.xls` 模板包括：

- `14N连杆部件边界图、P图和DFMEA.xls`：包含 `P图-0530`、`DFMEA-0530`、`边界图`、`P图`、`DFMEA`、`严重度S`、`频度O`、`探测度D`、`AP` 等 sheet。
- `K09LN-1004201-01A-DFMEA01.xls`：包含 `DFMEA`、`AP`、`更改控制页`。
- `K11-1004201-21-DFMEA01.xls`：包含 `DFMEA`、`AP`。

连杆 DFMEA 生成时只调用工具复制上述 `.xls` 模板到当前会话 artifact 目录；不得重新组织字段、生成 CSV 或把风险摘要包装成正式 DFMEA。

## 工作方法

1. 先读取用户需求、设计对象、已修改参数和证据文件。
2. 如 DFMEA 或规则表存放在数据库中，使用 `mysql_query` 查询；如证据来自用户工作区，使用 Beya Server 内置检索/文件能力获取，不调用 mc-design 旧 workspace 工具。
3. 按失效模式、原因、后果、预防控制、探测控制和建议措施整理风险。
4. 对缺证据或低置信度风险标记为“需人工复核”，不要做确定性结论。
5. 用户明确要求生成 DFMEA 时，调用 `mc_design_generate_dfmea_artifact`；该工具输出本地 `.xls` 模板副本，不依赖 Excel COM 或外部系统，也不修改模板内容。

## 输出要求

每条风险包含：对象、触发条件、潜在后果、依据、建议动作和是否阻断继续执行。

## 禁止事项

- 禁止普通建模请求自动生成 DFMEA；只有用户明确要求或工具入参显式 `include_dfmea: true` 时生成。
- 禁止把曲轴/凸轮轴风险摘要说成正式 DFMEA，除非已补齐对应模板证据。
